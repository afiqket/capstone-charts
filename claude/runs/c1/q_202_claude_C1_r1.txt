Clicking the center circle zooms out one level toward the root. The center circle's datum is bound to the current node's parent (`parent.datum(p.parent || root)` on each click), so clicking it triggers the same `clicked` handler with that parent node — animating the sunburst back outward to show the parent's level. If you're already at the root, `p.parent` is null so it falls back to `root`, effectively a no-op zoom that just re-renders the top-level view.
