## Why the chart won't give you the exact number

The chart has an interactive tooltip (hover over the area near year 2024), which shows per-region values. But it passes values through this formatter:

```js
const fmtTT = v => {
  if (v >= 1e9) return `${d3.format(".2f")(v / 1e9)} billion`;
  if (v >= 1e6) return `${d3.format(".2f")(v / 1e6)} million`;   // ← this branch applies
  return d3.format(",.0f")(v);
};
```

Since `430,034,750` is ≥ 1e6 but < 1e9, the tooltip would display it rounded as **"430.03 million"**, not the exact figure. The Y‑axis (`fmtY`, `.0f million`) is even coarser, and the stacked-area shape makes precise reading impossible anyway.
