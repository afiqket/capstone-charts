The `analytics` category has no direct `value` field in the JSON — only leaves carry values. Its value is computed by d3 at line 20-22:

```js
const hierarchy = d3.hierarchy(data)
    .sum(d => d.value)
    .sort((a, b) => b.value - a.value);
```

`d3.hierarchy(...).sum(d => d.value)` walks the tree and sets each internal node's `.value` to the sum of its descendants. So you read it via the hierarchy node's `.value` property — e.g.:

```js
hierarchy.children.find(d => d.data.name === "analytics").value
```
