**Short answer: Ukraine's death rate in year 2000 is `0`.**

There's only one value per country per year in this dataset, so "the highest death rate for Ukraine in 2000" is just that single data point:

```
Ukraine,UKR,2000,0
```

**How the chart code would retrieve it:**

1. `dataByCountry` is built via `d3.group(rawData, d => d.Entity)`, so `dataByCountry.get("Ukraine")` gives all of Ukraine's rows (1989–2024).
2. The helper `getValueForYear("Ukraine", 2000)` does the lookup:
   - `rows.find(r => r.Year === 2000)` finds the 2000 row,
   - returns `{ value: exact["Death rate in ongoing conflicts (best estimate) - Conflict type: all"], year: 2000, estimated: false }`,
   - which evaluates to `{ value: 0, year: 2000, estimated: false }`.

So `getValueForYear("Ukraine", 2000).value` → **0**.

**Context worth noting:** Ukraine's death rate is `0` for every year from 1989 through 2013. It only becomes non-zero starting in 2014 (`10.74`), spiking massively in 2022 (`225.60`). So the year 2000 specifically is a zero — Ukraine's *peak* death rate in the whole series is in **2022 (≈225.6 deaths per 100,000)**, not 2000. If you actually wanted Ukraine's maximum value, that's the row to look at:

```
Ukraine,UKR,2022,225.60483
```
